VOLUME CONTROLS

Use the shield to enable administrator operations. Quick format erases the selected volume. Reset erases every partition and creates one GPT data volume. Neither is a secure erase. Internal and system disks are excluded.

AUTOMATIC FLASH

Authorize a known drive on this computer. Actions run only while OMNIA is open; only the exact task approved on this computer can run.

Create your own task below. Automatic execution currently requires OMNIA running and separate authorization on each computer.

Program a task

Tasks run with normal user permissions. Review every command before authorizing; a script can change or delete files accessible to your account. The administrator shield does not elevate custom scripts.

The task is stored as OMNIA/AutomaticFlash.json. To use an updated task, remove the old file yourself and create a new one, then authorize it again. Windows enrollment is available here; Linux/macOS scripts can be authored, but receiving support for those platforms is not implemented yet.
