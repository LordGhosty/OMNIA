SYSTEM & ADMINISTRATION

Windows Repair_

Check and repair Windows components

Enable the administrator shield, then review an operation.

Checks report what Windows finds. Repairs can change system files and may need internet access or a restart. OMNIA does not restart the computer automatically.

OPERATION 

DISM log: %WINDIR%\Logs\DISM\dism.log · SFC log: %WINDIR%\Logs\CBS\CBS.log. A completed process does not by itself mean every problem was repaired; read the Windows result.
REVIEW OPERATION
Keep OMNIA open and the computer powered on until Windows finishes. This operation cannot be cancelled from OMNIA. Repairs are not generally reversible.
